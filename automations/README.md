# q-notes editorial assistance

Read `AGENTS.md` and [`docs/pipeline.md`](../docs/pipeline.md) at the start of each run.
Routines 03/03b/04 also read the existing material/form and critic contracts. Use the
current files rather than a pasted historical copy.

| File | Entry condition | Result |
|---|---|---|
| `01-topic-scout.md` | Optional scheduled discovery or requested reading | Useful reading/questions, or no candidate |
| `02-interview-brief.md` | Author chooses a subject and wants questions | One useful question, more only when needed |
| `03-drafter.md` | Explicit request or unconsumed author-marked Ready to draft | Authorized draft, private fragment, or no draft |
| `03b-editorial-critic.md` | A draft needs independent scope review | One compact critic result |
| `04-ship-gate.md` | Reviewed draft or author feedback | Readiness for explicit author publication |
| `05-gardener.md` | Optional maintenance review | Concrete upkeep; no output quota |

Capture is not drafting intent. Drafting intent is not publication approval. Neither a
calendar nor source expiry supplies either. Preserve original input and allow paused
work without downgrading or closing it for age. No mandatory A/B or retell exercises.

Content changes go through PR review. Research paths and PR bodies in this public repo
are public too; do not copy private input there or claim it becomes private behind login.
A no-action result can be reported in the run response without a repository write.
Notifications require an authorized channel and a useful result or decision.

See `docs/pipeline.md` §8 for the runtime inventory and limits. Editing these files does
not change an external schedule, deploy a Worker, or update copied scheduler prompts.
