# Interview: Manufacturers already know the model isn't the problem; nobody built the handoff rule

**Source:** backlog item 2026-08-10 — Manufacturers already know the model isn't the problem; nobody built the handoff rule
**Status:** Awaiting answers

## The idea in three sentences

Two independent pieces in the two weeks before this scout run — a July 24 manufacturing trade-press piece and an August 3 Forbes piece by a former MultiOn founding member — both cite Deloitte's finding that roughly three-quarters of manufacturers plan to deploy agentic AI within two years, but only about one in five have a governance model mature enough to do it reliably. The gap isn't model capability; it's that almost no manufacturer has a deliberate, per-decision rule for when a factory agent acts alone versus when it stops and asks a human — the same organizational-absorption argument the author has already made about coding agents, now applied to physical operations. The strongest objection is that the trade coverage is thin on named companies and verifiable incidents, so the thesis is plausible but currently unproven without a concrete example.

## Questions

1. In the manufacturing or industrial clients you've worked with, has anyone actually written down which decisions an AI system is allowed to make alone versus which ones need a human — or is that boundary still informal, tribal knowledge?
   → a client where the rule was written down, even informally
   → or: you've only ever seen it stay tribal knowledge, decided in the moment
   → push: writing the rule down doesn't matter if nobody follows it once alert fatigue sets in

2. If you had to write the one-sentence handoff rule for a client today — the line that decides when their factory agent stops and asks a human instead of acting on its own — what would it actually say, and what would decide where you drew the line?

3. You said in the chip-design interview that you don't want to pretend to be a hardware expert. What's the version of this question you do have firsthand standing on: not "what should a factory agent be allowed to do," but "what happens in a company when nobody has decided that yet"?

4. In "Cheap agents create coordination debt" you wrote: "Agents don't remove those questions. They multiply the number of moments when those questions should have been asked." Does that same mechanism hold when the moments are physical — reordering parts, replanning a production line — or does a factory floor change the stakes enough to make it a genuinely different problem than the software one?

5. Which part of this thesis would you actually bet against: that manufacturers already have documented handoff rules the trade press just isn't seeing, or that governance will simply catch up to deployment before this becomes a real incident?
