# Interviews

Optional questions for author-selected material (`automations/02-interview-brief.md`).
Keep the existing `YYYY-MM-DD-<slug>.md`, numbered questions, and `## Author answers`
format for phone compatibility. Ask one useful question; more are optional.

English, 中文, mixed input, and fragments are welcome. Saving answers is not drafting
intent. Only explicit author authorization or a current author-marked `Ready to draft`
allows drafting from the supplied material. Unsigned answers stay untouched, even near
expiry; no answers does not trigger a smaller replacement piece. A complete existing
draft needs no interview. Publication requires separate approval after bilingual preview.

This directory is in a public repository. Do not copy private original material here.
Preserve existing records; follow #142 for any storage migration and access boundary.
