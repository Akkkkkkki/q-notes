# Voice samples

Writing the author actually produced and would sign off as "sounds like me": 朋友圈长文,
work-email fragments, internal docs, podcast or voice-memo transcriptions, retell
exercises from interviews. This corpus exists so the voiceprint (`research/voice.md`)
is distilled from the author's real language, not inferred from vibes.

Consumers: the **gardener** mines this directory monthly for voiceprint candidates
(`## Proposed` in `voice.md`); the **drafter** may read it for texture but quotes from
it only via promoted voiceprint entries or the verbatim spine.

## Privacy rule (decided 2026-07-17 — this repo is public)

- **Raw material never enters this repo.** Full chat logs, emails, internal docs, and
  unredacted transcripts stay on the author's machine or private storage.
- What goes here: **excerpts the author has screened** — names, clients, employers, and
  identifying details removed or generalized ("a client" not the company name).
- The author does the screening before committing; automations never copy material into
  this directory from anywhere except interview files already in this repo.
- If in doubt, keep the raw text out and add only the distilled voiceprint entry.

The author can revisit this rule (e.g. if the repo goes private), by editing this file.

## Format

One file per source or batch: `YYYY-MM-DD-<slug>.md`. Each file starts with:

```md
# <short description of the source>

**Register:** spoken | written
**Language:** en | zh | mixed
**Source:** wechat voice memo | work email | internal doc | podcast | retell exercise | ...
```

then the excerpts, one blank line between them. Register matters: chat and voice memos
are spoken register — raw material for the voiceprint, never copied straight into a
post. Entries mined from spoken sources carry a `spoken register` tag in `voice.md` and
get adapted (keep the word choices, tighten the syntax) before appearing in prose.

## What makes a good sample

- The author wrote or said it, and reading it back they think "我说过这话" — not "写得还行".
- Rough is fine; rough is the point. Don't polish before committing.
- A strong opinion, a characteristic phrasing, or a natural 中英混排 moment beats length.
